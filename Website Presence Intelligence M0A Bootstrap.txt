## How Cursor is configured in this repository

Cursor loads all of these. Do not delete the Claude Code files. They remain the policy source.

- AGENTS.md is the Cursor operating contract.
- CLAUDE.md holds the same product rules.
- .cursor/rules/*.mdc holds the short always-on rules. Code rules apply to TypeScript and CSS.
- .cursor/skills/ links to .claude/skills/. There is one copy of each skill.
- .cursor/agents/ holds the build subagents. When a name exists in both places, .cursor/agents/ wins.
- .cursor/hooks.json runs .cursor/hooks/gate.py. The script reads hook_event_name and calls the checks in .claude/hooks/. Exit code 2 denies the action. A hook that cannot start does not deny the action.
- .cursorignore blocks Agent, Tab, and @-mentions from secret files. The terminal is gated by the shell hook, not by the ignore file.

M0A in docs/spec/06-MODEL-PLAN.md is planned as opusplan at high effort, with security-reviewer and verifier before the pull request. Cursor has no fable, opus, opusplan, sonnet, or haiku alias.
